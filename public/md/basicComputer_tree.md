## 樹狀結構

*   **歪斜樹 (Skewed)**：每個節點最多只有 1 個子節點
*   **嚴格二元樹 (Strictly Binary Tree)**：
    *   **不准生獨生子**
    *   每一個非樹葉節點（內部節點）都必須有剛好 0 或 2 個子節點
*   **完滿二元樹 (Full Binary Tree) & 完美二元樹 (Perfect Binary Tree)定義**：
    *   **完美的正三角形**
    *   一棵高度為 k，且擁有剛好 2^k - 1 個節點的二元樹。
    *   第 i 層，最多有 2^(i-1) 個節點。
*   **完整二元樹(Complete Binary Tree)**：
    *   **乖乖從左邊排隊，不能有空隙**
    *   由左至右填滿，不准有人中途插隊，但最後一排可以沒排滿。
    *   能當陣列 (Array)看待，從 1 開始編號 (1-based indexing)
```text
               [1] A  (根節點 Root)
              /   \
           [2] B   [3] C
          /   \   /
       [4] D [5] E [6] F

        *   i為某陣列的索引，
        *   左小孩的位置：2i
        *   右小孩的位置：2i + 1；
        *   父節點 (爸爸) 的位置：Math.floor(i/2)  // 無條件捨去
        陣列長相：[ -, A, B, C, D, E, F ]
        對應索引：[ 0, 1, 2, 3, 4, 5, 6 ]
```

### 二元樹走訪
*   **BFS (廣度優先搜尋)，佇列(Queue，FIFO)**
    *   層序 Level-order：一層一層由上而下，且由左至右
    *   完整二元樹的陣列表示法，用層序的方式 拆成 陣列。但預設 Array[0] 空著不用，Root 放在 Array[1]
*   **DFS (深度優先搜尋)，遞迴**
    *   每個節點都有左（左小孩）、中（自己）、右（右小孩）。
        *   所謂的「前序、中序、後序」，完全是看「中（自己）」排在哪個位置。
    *   前序 Preorder：中 → 左 → 右    ROOT必定在最前
    *   中序 Inorder：左 → 中 → 右     ROOT剛好在中間
    *   後序 Postorder：左 → 右 → 中   ROOT必定在最後
```text
               ( A )
              /     \
           ( B )   ( C )
          /     \
       ( D )   ( E )
    ABDEC
    DBE A C
    DEBCA
    *   只有「前序+中序」或「中序+後序」能唯一決定一棵樹
```

### 二元搜尋樹(BST)
1.  左子樹都比自己小、右子樹都比自己大
2.  平均搜尋 O(log n)、最壞 O(n):當資料按順序插入，BST 退化成歪斜樹(像一條鏈結串列)。
3.  對 BST 做中序走訪 (Inorder)，會得到由小到大排序的結果
4.  平衡樹(如 AVL、紅黑樹) 會透過旋轉維持左右高度平衡，避免退化成歪斜樹，保證 O(log n)。
5.  底層是指標
*   **BST 的插入與刪除**：
    *   插入：從根開始比大小，比目前節點小往左、大往右，一路走到空位就掛上去。
    *   刪除分三種情況：
        1.  葉節點(沒有子節點)：直接刪掉。
        2.  只有一個子節點：用那個子節點頂上來取代它。
        3.  有兩個子節點：中序前驅(左子樹的最大值)、中序後繼(右子樹的最小值)，兩者擇一即可。

### 堆積 (Heap)
1.  完整二元樹
2.  
    *   最大堆 (Max-Heap)：每個節點都 ≥ 它的子節點 → 根最大。
    *   最小堆 (Min-Heap)：每個節點都 ≤ 它的子節點 → 根最小。
3.  能以陣列表示
4.  只要知道自己所在的陣列位置 (Index 設為 i)，左小孩一定在 2i，右小孩一定在 2i+1，父節點 Math.floor(i/2)。
5.  用途：優先權佇列 (Priority Queue)，因為最大值或最小值，一定在根。
    *   O(1)，知道最大或最小
    *   抓走後 只要花 O(log n) 的時間調整一下樹狀結構；
        *   先把陣列尾巴，抽出來放到第一個 (當作根)
        *   為了滿足 HEAP 規則，把這新的根由上至下，不停交換
    *   堆積排序 (Heap Sort,O(n log n))。
        *   建堆積 (Build Heap)，時間是 O(n)。
        *   重複抓取與調整，每次調整是 O(log n)

### 運算式表示法
1.  運算式數
    *   葉節點 (Leaves)：放運算元（數字或變數，例如 A, B, C）。
    *   內部節點 (Internal Nodes)：放運算子（例如 +, -, *, /）。
    ```text
          ( + )
         /     \
       ( A )   ( * )
              /     \
           ( B )   ( C )
    ```
2.  
    1. 中序，人類習慣寫法，缺點是需要()來決定優先權，但對電腦來說難以解析
        *   當子傑點(小孩)的運算子優先權低於爸爸（根節點）時，這個小孩的子樹在印出來時，就必須強制加上括號 ( )
        *   A + B * C
    2. 前序表示法
        *   **+ A * B C**
        *   運算子在前，不需要()
        *   可以利用 Stack，由**右至左**取得答案
            1. 掃到 C：是運算元 ➔ 推入 Stack。（Stack 頂端：C）
            2. 掃到 B：是運算元 ➔ 推入 Stack。（Stack 頂端：B, C）
            3. 掃到 *：是運算子 ➔ 從 Stack 依序彈出兩個元素：
                * 第一個彈出：B（左運算元）
                * 第二個彈出：C（右運算元）
                * 計算 B * C，把結果推回 Stack。
            4. 掃到 A：是運算元 ➔ 推入 Stack。（Stack 頂端：A, (B*C的結果)）
            5. 掃到 +：是運算子 ➔ 從 Stack 依序彈出兩個元素：
                * 第一個彈出：A（左運算元）
                * 第二個彈出：(B*C的結果)（右運算元）
                * 計算 A + (B * C)，把最終結果推回 Stack。
    3.  後序表示法
        *   A B C * +
        *   運算子在後，不需要()
        *   可以利用 Stack，改成由**左至右**取得答案

### AVL樹
平衡因子：左子樹高度 - 右子樹高度 = {-1, 0, 1}。
1. **插入流程 (中位數法，可以應用在刪除)**：
    1. 照 BST 規則，新節點掛在 null 的位置，一定是葉 (放在對應位置)
    2. 往上退，尋找失衡的爺爺節點
    3. 從爺爺 往下走兩步，鎖定「關鍵三節點」 找出爺爺、爸爸、孫子 (孫子若一樣高，挑選能與爺爸一直線的)
    4. 中位數法(選擇題用)：
        1. 找出排在中間的那個數字（中位數）。
        2. 把這個中位數直接往上提拔，讓它取代原本爺爺的位置，成為這個局部子樹的新根節點。
        ps. 萬一 把中位數往上拉的時候，中位數原本底下可能已經有掛著其他子樹，因為老大搬家，變成孤兒。
        3. 把孤兒的根節點數字0，從根開始跑，拿去跟剛剛重組好的三個關鍵節點比大小，放到對應的位置。
    5. 剩下兩個點，依「小左大右」歸位
2. **往下走兩步，找出形狀。利用形狀，找出對應的旋轉方式**：
    1.  LL 型 (左左失衡)： 節點的左子樹過高，且新節點插在「左子樹的左側」。解法： 對失衡節點作單次右旋 (Single Right Rotation)。
    2.  RR 型 (右右失衡)： 節點的右子樹過高，且新節點插在「右子樹的右側」。解法： 對失衡節點作單次左旋 (Single Left Rotation)。
    3.  LR 型 (左右失衡)： 節點的左子樹過高，但新節點插在「左子樹的右側」。解法： 雙重旋轉。先對左子節點左旋（轉成 LL 型），再對失衡節點右旋。
    4.  RL 型 (右左失衡)： 節點的右子樹過高，但新節點插在「右子樹的左側」。解法： 雙重旋轉。先對右子節點右旋（轉成 RR 型），再對失衡節點左旋。
3. **N(h)** = 「高度是 h 的 AVL 樹,最少要幾個節點」
    *   N(h) = N(h−1) + N(h−2) + 1 (前兩項相加，再 +1)
    *   N(0) = 0、N(1) = 1

### 紅黑樹
黑高：bh(x) = 從 x 往下，到任一 NIL 的路徑上，黑節點的個數
**定義**：
1.  是BST
2.  根是黑
3.  每個葉節點(NIL)是黑
4.  紅節點的兩個小孩都是黑
5.  從任一節點到其下方每一個 NIL,經過的黑節點數目相同
**結論**：
1.  黑高 b ，內部節點數介於 2^b - 1 (完美二元樹，沒有紅節點) ~ 2^2b - 1，要盡可能添加紅節點，黑紅交替
2.  b <= h <= 2b
3.  含 NIL 時，黑節點必定比紅節點多
4.  只算內部節點時，黑比紅多是錯的 ✗ (紅最多可達黑的 2 倍)  ex. 黑紅
**插入規則(中位數版)**：
0.  新節點 Z，父節點P，祖父節點 G 以及叔叔節點 U
1.  將新節點 Z 依照「左小右大」的規則插到樹的最底層，並塗成紅色
2.  P是黑色，結束。P是紅色，要進行修正。
3.  U是紅色，P、U塗黑，G塗紅。上拋檢查： 因為G 變紅了，把 G 視為新的 Z，檢查它和它的父親有沒有再度發生連續紅。U是黑色，G、P、Z排列順序。
4.  G、P、Z，中位數當老大，然後中位數塗黑。剩餘兩個當左子及右子，塗紅。
5.  孤兒歸位（掛回子樹），原本掛在這三個節點底下的所有子樹（包含剛剛在一旁的U），現在變成無家可歸的孤兒。請把它們當作一般的數值，從剛剛重組好的新老大開始，依照「左小右大」的規則重新塞回去。
6.  根節點塗黑(鐵律)
