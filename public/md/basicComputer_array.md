## 陣列與線性資料結構

### 陣列
連續記憶體、大小固定的一排格子，用索引 (index) 存取。
*   **二維陣列**：
```text
A[3][4] (3 列 4 行,索引從 0) 
     行0  行1  行2  行3
列0  A00  A01  A02  A03
列1  A10  A11  A12  A13
列2  A20  A21  A22  A23
純粹排序問題:
以列為主；C類型的語言，列跑完，在跳行
以行為主；
```
*   A[2..4][3..5]  [下界..上界]表示法，**索引的範圍**。表示列是從 2 ~ 4，但行3 ~ 5
*   陣列 隨機存取 O(1)、插入/刪除 O(n)、大小固定。
*   記憶體位址計算
    *   假設一二維陣列 A[1..5][1..4]，每個元素佔 2 bytes，起始位址為 1000。在分別以列為主、以行為主的情況下，請問 A[3][2] 的記憶體位址為何？
```text
11	12	13	14
21	22	23	24
31	32	33	34
41	42	43	44
51	52	53	54
*   以列為主，由左至右，到尾巴，在跳列。    1014
*   以行為主，由上至下，到底部，在跳行。    1014
```
### 動態陣列
*   本質上還是陣列（連續記憶體）。當陣列滿了還要塞資料時，系統會在記憶體其他地方**找一塊「兩倍大」的連續空間**，把舊資料全部搬過去，再釋放舊空間。
*   一般的新增 (Append)：O(1)。
*   觸發擴容的該次新增：必須搬移所有資料，時間複雜度退化為 O(n)。
*   國考考點：雖然最差是 O(n)，但經過「攤還分析」後，平均新增時間複雜度仍視為 O(1)。
```java
// 建立一個空的動態陣列 (專門裝字串)
ArrayList<String> box = new ArrayList<>();
// 無中生有(從後方插入)
box.add("感冒藥"); // O(1)
// 插隊，如果有移動後面的資料，是O(n)
box.add(1, "頭痛藥");     
// 讀取 索引 的值
String firstItem = box.get(0);
// 直接覆寫：找到該位置，直接替換新值。 (O(1))
box.set(2, "益生菌"); 
// 刪除索引 0 的「感冒藥」。後面的藥會自動往前遞補！
box.remove(0);
// 點名，看現在實際裝了幾個藥
int total = box.size();
```

### 鏈結陣列/連結串列/Linked List
0.  執行期，才配置記憶體，不浪費空間、不溢位
1.  耗費空間較大，因為除了資料，還需要儲存指標
3.  BIGO
    1.  插入/刪除 O(1)
    2.  走訪/存取 O(n)
4.  種類
    1.  單向 (Singly)：一個 next 指標(尾接 null)，只能往前走。
    2.  雙向 (Doubly)：有 prev + next，可雙向走訪。
    3.  環狀 (Circular)：最後一個節點指回第一個，繞成一圈。

### 堆疊 (stack)：後進先出 LIFO。
1. 本質其實是 interface，但JAVA沒設計好，所以可以寫成以下。
```java
Stack<Integer> st = new Stack<>();
st.push(1);            // 放入 1
int top = st.peek();   // 偷看最上面(不取出)1
int a = st.pop();      // 取出最上面 1
```
2. **經典應用**：
    1. 括號配對檢查，左括號：壓進堆疊；右括號：配掉一個左括號
    2. 副程式呼叫 (Function Call) 與 遞迴 (Recursion)：系統用來記錄函式的執行順序與返回位址。
    3. 網頁瀏覽器的「上一頁 (Back)」功能。
    4. 算術表示式轉換：中序轉後序、中序轉前序（編譯器處理數學公式的核心）。
        * 電腦在底層其實會同時開啟兩個 Stack 來分工合作：
            1.  數字堆疊 (Number Stack)： 專門用來放數字。
            2.  符號堆疊 (Operator Stack)： 專門用來放 + - * / 和 ( )。
            3.  電腦的最高指導原則（門禁規則）只有兩條：
                *   規則 A（權重壓制）： 準備進 Stack 的符號，如果權重「小於或等於」Stack 頂端的符號，就必須把頂端符號踢出來，並從數字堆疊抽出兩個數字「先算」，算完的結果再丟回數字堆疊。
                *   規則 B（括號特權）： 左括號 ( 權重最高，可以直接進場。遇到右括號 ) 時，就一路把符號踢出來計算，直到撞見左括號為止。

### 佇列 (Queue)：先進先出 FIFO (First-In, First-Out) (音同Q)
0.  像排隊，先到的先服務。(習慣上是尾端進，前端出)
1.  雙向開口：
    1.  Rear (尾端)：只負責加入資料 (Enqueue)   ,O(1)。
    2.  Front (前端)：只負責拿出/刪除資料 (Dequeue) ,O(1)。
3. Queue 是介面 (Interface)，
    ```java
    Queue<String> q = new ArrayDeque<>(); // 動態"環形陣列"，效能好
    // Queue<String> q = new LinkedList<>(); // 雙向鏈結串列，記憶體開銷大
    // 把元素排到隊伍的最後面。
    q.offer(e);
    // 把隊伍最前面的元素拿出來並刪除。
    q.poll();
    // 看隊首
    q.peek();
    ```
4. **環狀佇列**
    0. 是為了要解決 Queue + Array ，假溢位(前方有空位、後方沒空位)
    1. 環狀佇列如何改善 → 使用取餘數 (mod) 運算。例如 Rear = (Rear + 1) mod MaxSize。
    2. 如何判斷空與滿 
        1. 犧牲一格(最常見)。
            *   為了區分「佇列全空」還是「佇列全滿」，環狀佇列必須犧牲一個空格不使用。
            *   佇列空：Front == Rear。
            *   佇列滿：(Rear + 1) mod MaxSize == Front。
        2. 額外用計數器 count — 記錄目前有幾個元素。(極少)
            *   空:count == 0; 滿:count == size(enqueue 時 count++、dequeue 時 count--)。好處:可以裝滿全部 m 格。

5.  **雙向佇列（Deque）** 發音同 "Deck"
    1.  存取規則：前後兩端都可以進行插入 (Insert) 與刪除 (Delete) 動作。
    2.  輸入受限的雙端佇列 (Input-Restricted Deque)：
        *   限制：只能從「一端」插入，但可以從「兩端」刪除。
    3.  輸出受限的雙端佇列 (Output-Restricted Deque)：
        *   限制：只能從「一端」刪除，但可以從「兩端」插入。
    4.  
```java
Deque<String> line = new ArrayDeque<>();

// 從前端加入 (特權插隊到最前面)
line.offerFirst("VIP特權客"); 
// 從尾端加入 (類似一般的 Queue 正常排隊)
line.offerLast("正常客A");        

// 看前端
System.out.println("隊伍最前面的是誰: " + line.peekFirst()); // 印出: VIP特權客
// 看尾端
System.out.println("隊伍最後面的是誰: " + line.peekLast());  // 印出: 正常客B

// 拔除前端
String served1 = line.pollFirst();
// 拔除尾端
String cancelled = line.pollLast();
```
