# 邏輯閘與循序組合電路重點筆記

## 基礎邏輯閘
*   **NOT**：反相，輸出結果0/1對調，表示法：A'、NOT A
*   **NAND**：AND後反相(負或閘)，全為1才輸出0，表示法：(AB)'
*   **NOR**：OR後反相(負及閘)，有一個1就輸出0，表示法：(A+B)'
*   **XOR**：互斥或，輸入不同輸出1，表示法：A ⊕ B、A'B + AB'
*   **XNOR**：相等判斷，輸入相同輸出1，表示法：(A⊕B)'、AB + A'B'

*   NAND 或 NOR 「沒有結合律」，也就是 其運算的先後順序**會**影響最終結果
*   **德摩根定律 (De Morgan's Laws)**：(AB)' = A' + B'；(A+B)' = A'B' (穿過括號後反向，等於 每個值反向 且 AND/OR 對調)

## 真值表轉電路與卡諾圖
### 把真值表變成電路：
*   **SOP**：抓輸出1，遇0反項，積項和，非常容易直接轉換成全部都用 NAND 閘
*   **POS**：抓輸出0，遇1反項，和項積，非常容易直接轉換成全部都用 NOR 閘

### 卡諾圖畫簡 (電路簡化，電路轉成表格)
0. **製作卡諾圖**：
    1. n個變數，總共會有 2^n 個格子。
    2. 在有限的標頭格子內，決定表格的各標頭，用「格雷碼」的方式變化。
1. **圈 2的n次方個**，圖案樣式不限：
    1. 圈越大越好，且只留大圈。
    2. 每一個圈圈裡面，都必須至少包含一個「沒被其他圈圈蓋到的 1」。
2. **比較圈**，所對應的變數(非值)，變數沒變，留下；有變，淘汰。
3. 第二步驟的變數為0，反相表示。同圈的變數之間，相乘。
4. 重複 2-3 把其他的變數留下。
5. 把所有圈，得到的變數積，相加。

*   **Don't care (X)** 代表該輸入組合不會發生或結果無所謂，可代表0或1。
*   卡諾圖4個角能圈成一組。
*   `F = ∑m(0,2,4,6)` 表示在變數組合的十進位數值為 (0,2,4,6) 的情況下，F 為 1。

## 萬用閘與電路形式
*   **萬用閘**：
    *   **NAND**：(1) NOT (2) AND (3) OR (4) XOR (5) XNOR
    *   **NOR**：(1) NOT (2) OR (3) AND (4) XNOR (5) XOR
*   **電路形式**：
    *   SOP：AND-OR 或 NAND-NAND
    *   POS：OR-AND 或 NOR-NOR

## 循序電路與組合電路

### 循序電路 (Sequential Circuit)
1. 跟著「時脈」打節拍，利用「回授」生「記憶」，結合「現在與過去」決定輸出。
2. **範例**：
    1. **正反器 (Flip-Flop)**：只能記住且維持 1 bit 的資料 (0或1)。
        *   `Q = (S AND Q')'`
        *   `Q' = (R AND Q)'`
    2. **暫存器 (Register)**：多個正反器。
    3. **計數器 (Counter)**
    4. **隨機存取記憶體 (RAM)**：SRAM (正反器) / DRAM (電容+電晶體)。

### 組合電路 (Combinational Circuit)
1. 現代的輸出，完全只由現在的輸入來決定。
2. 純粹由基本邏輯閘組成。
3. **範例**：
    1. **加法器 / 減法器 (Adder / Subtractor)**
    2. **多工器 (Multiplexer, MUX)**：多選一 (一入口多出口)。
    3. **解多工器 (Demultiplexer, DeMUX)**：一分多 (多入口一出口)。
        *   **選擇線 (Select Lines)**：n條選擇線，可以控制 2^n 條資料線 (控制 mux 或 demux)。
    4. **編碼器 (Encoder)**：將人類語言翻譯成機器語言。
    5. **解碼器 (Decoder)**：翻譯給人類看。
    6. **比較器 (Comparator)**：if-else。

## 四大正反器特徵
*   **SR正反器**：S=1設1 / R=1清0 / 雙1當機。
*   **JK正反器**：J=1設1 / K=1清0 / 雙1反轉。
    1. **JK 變 T**：J 與 K 綁在一起 (J=K)。
    2. **JK 變 D**：中間加 NOT 閘 (J=D, K=D反相)。
*   **D正反器**：單一輸入 / 輸入=存取。
    1. 暫存器
    2. 儲存
    3. 延遲速度最低
    4. `Q(t+1) = D`，下一個時間點（下一個時脈打來時）的輸出狀態。
*   **T正反器**：單一輸入 / 1就反轉，0就不變。
    1. 計數器
    2. 除頻器
    3. 數數
    4. `Q(t+1) = T XOR Q`，下一個時間點輸出的狀態。
        *   當 T = 0 時：`0 ⊕ Q = Q`（下一個狀態 = 現在的狀態，維持不變）。
        *   當 T = 1 時：`1 ⊕ Q = Q'`（下一個狀態 = 現在狀態的反相，也就是 0 變 1、1 變 0 的反轉）。

## 正反器與閂鎖器差異
*   **時脈有「三角形」= 正反器 (邊緣觸發)**
    *   正反器 (有三角形)：資料的更新只發生在時脈訊號「瞬間跳變」的那一個極短瞬間。(例如：快門只有在按下才觸發)
    <img src="/images/正反器.png" style="width: 30%;" alt="正反器">
*   **時脈沒三角形 = 閂鎖器 (位準觸發)**
    *   閂鎖器 (沒三角形)：只要維持在某個電位（不管是 1 還是 0），門就一直開著，容易受到干擾。(例如：大門)
