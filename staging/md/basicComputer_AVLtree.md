### AVL樹
平衡因子：左子樹高度 - 右子樹高度 = {-1, 0, 1}。
1. **插入流程 (中位數法，可以應用在刪除)**：
    1. 照 BST 規則，新節點掛在 null 的位置，一定是葉 (放在對應位置)
    2. **尋找失衡點 (爺爺)**：從新節點往上檢查平衡因子 (左右子樹高度差)。遇到第一個「高度差 2」的節點，它就是**爺爺**。
    3. 從「爺爺」開始，往新插入節點的方向往下走兩步。這三個連續的節點就是**爺爺、爸爸、孫子** 
        *   若遇到高度相同的情況，挑選能與爺爺、爸爸連成一直線的孫子
    4. 中位數法(選擇題用)：
        1. 找出排在中間的那個數字（中位數）。
        2. 把這個中位數直接往上提拔，讓它取代原本爺爺的位置，成為這個局部子樹的新根節點。
        3. 把孤兒的根節點數字0，從根開始跑，拿去跟剛剛重組好的三個關鍵節點比大小，放到對應的位置。
    5. **小左大右歸位**：剩下的兩個關鍵節點，比新老大**小**的掛左邊，比新老大**大**的掛右邊。
    6. **安頓孤兒 (父節點消失的節點)**：
        * 在提拔中位數的過程中，中位數原本底下掛著的子樹可能會因為位子被搶走而變成「孤兒」。
        * **解法**：把孤兒的根節點，拿去跟剛剛重組好的三個關鍵節點**重新比大小**，依照 BST 規則重新掛到對應的空位上！

    *   範例，以下插入數字25
        ```text
              60   
             /  \
           20    80            
          /  \     \
        10    40    90
             /  \
           30    50       

        左右子樹高度差 1
        ```
        1. 插入流程
        ```text
               60
              /  \
            20    80
           /  \     \
         10    40    90
              /  \
            30    50
           /
        (25) <-- 新增的小傢伙      
        ```
        2. 往上退，尋找爺爺節點
        從剛插入的 25，一路往上檢查平衡因子（左右子樹高度差）：<br>
        看 30：左高1，右高0 => 差 1 (OK)<br>
        看 40：左高2 (底下有30, 25)，右高1 (底下有50) => 差 1 (OK)<br>
        看 20：左高1 (只有10)，右高3 (經過40到最底的25) => 差 2 (抓到了！失衡！)

        3. 鎖定「關鍵三節點」 (爺爺、爸爸、孫子)
            *   爺爺 20
            *   從爺爺開始，往新插入節點的方向往下走兩步
                *   爸爸 40
                *   孫子 30
            *   重組目標，20/40/30
        4. 中位數法 + 小左大右歸位
            *   改成由中位數當老大 30
            *   剩下的兩個點，依照「小左大右」掛在 30 旁邊

            ```text
               30   <-- 新老大
              /  \
            20    40
            ```
        5.  
            1. 30 移動位置，25變成孤兒
            ```text
                       60
                      /  \
                    30    80
                   /  \     \
                 20    40    90
                 /    /  \
               10   X    50
                   /
                (25) <-- 變成孤兒      
            ```
            2. 25從新老大開始往下比：
                1.  25<30 往左走
                2.  25>20 往右走
                3.  塞入空位
            ```text
                    60
                   /  \
                 30    80
                /  \     \
              20    40    90
             /  \     \
            10  25     50
            ```

2. **找出對應的旋轉方式**：
    1.  LL 型 (左左失衡)：爺爸孫連成一條往左下的直線 (/)。解法： 對失衡節點作單次右旋 (Single Right Rotation)。
    2.  RR 型 (右右失衡)：爺爸孫連成一條往右下的直線 (\)。解法： 對失衡節點作單次左旋 (Single Left Rotation)。
    3.  LR 型 (左右失衡)：爺爸孫連成一個「<」型的折線（先往左下、再往右下）。解法： 雙重旋轉。先對左子節點左旋（轉成 LL 型），再對失衡節點右旋。
    4.  RL 型 (右左失衡)：爺爸孫連成一個「>」型的折線（先往右下、再往左下）。解法： 雙重旋轉。先對右子節點右旋（轉成 RR 型），再對失衡節點左旋。

3. **N(h)** = 「高度是 h 的 AVL 樹,最少要幾個節點」
    *   高度為 h 的最小節點 AVL 樹，其結構就是：一個根節點 + 一個高度 h-1 的最小 AVL 子樹 + 一個高度 h-2 的最小 AVL 子樹
    *   **N(h) = N(h−1) + N(h−2) + 1 (前兩項相加，再 +1)**

### 紅黑樹
*   黑高：bh(x) = 從 x 往下，到任一 NIL 的路徑上，黑節點的個數
*   紅黑樹的 NIL 葉節點：是每個內部節點缺少小孩的那個位置所連到的東西 (與一般BST定義不同)
*   **定義**：
    1.  是BST，左子樹都比自己小、右子樹都比自己大
    2.  根是黑
    3.  每個葉節點(NIL)是黑
    4.  紅節點的兩個小孩都是黑
    5.  從任一節點到其下方每一個 NIL,經過的黑節點數目相同
*   **結論**：
    1.  黑高 b ，內部節點數介於 2^b - 1 (完美二元樹，沒有紅節點) ~ 2^2b - 1，要盡可能添加紅節點，黑紅交替
    2.  b <= h <= 2b
    3.  含 NIL 時，黑節點必定比紅節點多
    4.  只算內部節點時，黑比紅多是錯的 ✗ (紅最多可達黑的 2 倍)  ex. 黑紅
*   **插入規則(中位數版)**：
    1.  新節點一律是「紅色 (R)」。
    2.  發生連續兩個紅色 (Double Red) 時，先看「叔叔的顏色」：
        *   🛑 狀況一：叔叔是「紅色」 ➔ 【變色法 (Color Flip)】
            *   爸爸和叔叔變黑色，爺爺變紅色。然後把「爺爺」當成新的當前節點，繼續往上檢查。
            *   因為紅色是危險的顏色，所以爺爺變成新焦點

        *   ⚫ 狀況二：叔叔是「黑色」 (或 NIL) ➔ 【中位數法登場！】
            1.  抓出「爺、爸、孫」三個關鍵節點。
            2.  把中位數提拔當新老大。
            3.  新老大塗成「黑色」，底下的兩個小孩塗成「紅色」。
            4.  安置孤兒：
                1.  從局部的「新老大」開始 由上 至下，找到孤兒的位置 (比大小)
                2.  孤兒的孩子，整包一起跟著走   
                3.  孤兒的顏色不用變動

    3.  範例
        *   狀況一，插入數字30
        ```text
            60(B)  <-- 爺爺是黑色
           /     \
        40(R)   80(R)  <-- 爸爸是紅色，叔叔也是紅色！
        ```
        ```text
              60(R)  <-- 爺爺變紅色 (危機往上傳遞)
             /     \
          40(B)   80(B)  <-- 爸、叔變黑色
           /
        30(R)           <-- 新插入的一定是紅色
        ```
        *   狀況二-簡單版
        ```text
            60(B)  <-- 爺爺
           /     \
        40(R)   NIL(B) <-- 爸爸是紅色，叔叔是空的(黑)！


            60(B)   <-- 爺爺
           /     \
        40(R)   NIL(B)  <-- 爸爸 (紅) / 叔叔是 NIL (黑)！
           \
          50(R)  <-- 新節點，發生連續紅！

        先用中位數法，調整新排版。
        上色，老大塗黑，小孩塗紅。              
            50(B)  <-- 中位數升官當老大，塗黑色！
           /     \
        40(R)   60(R)  <-- 剩下兩個當小弟，塗紅色！
        ```
        *   狀況二-孤兒版，插入數字 45
        ``text
                80(B)
               /     \
           [40(R)]   100(B)  <-- 100 是等一下的黑叔叔
           /     \
        20(B)   [60(B)]      <-- 60 是等一下的關鍵主角
                /     \
             50(R)   70(R)
        ```
        ``text
                80(B)
               /     \
           [40(R)]   100(B) 
           /     \
        20(B)   [60(B)]      <-- 60 爺爺
                /     \
             50(R)   70(R)  <-- 爸爸紅 / 叔叔紅
              /
           45(R)            <--  新節點， 45與50 產生衝突

        找到了 爺爺/爸爸/孫子，採用變色法，爸叔黑、爺變紅

                80(B)
               /     \
           [40(R)]   100(B) 
           /     \
        20(B)   [60(R)]      <-- 60 變色
                /     \
             50(B)   70(B)  <-- 爸叔變色
              /
           45(R)

        60(R)變成新焦點，往上探討，發現 40 是紅色。
        違法兩個紅色不能連續，觸發 發生連續兩個紅色 (Double Red) 時，先看「叔叔的顏色」，叔叔是黑色
        觸發：中位數法
        1.  爺爺 80、爸爸 40、孫子 60
        2.  把中位數 60 變成新老大
        3.  40掛左邊、80掛右邊
        4.  重新上色，新老大塗黑、小弟塗紅      

             60(B)  <-- 升官當老大 (塗黑)
           /     \
        40(R)   80(R) <-- 變小弟 (塗紅)

        5.  安頓孤兒
            1.  60變成老大，50、70變成孤兒
            2.  從局部的「新老大」開始 由上 至下，找到孤兒的位置
                新老大是60
                * 50 < 60 (左) ➔ 遇到 40 ➔ 50 > 40 (右) ➔ 50(B) 掛在 40 的右邊空位
                * 70 > 60 (右) ➔ 遇到 80 ➔ 70 < 80 (左) ➔ 70(B) 掛在 80 的左邊空位
                * 孤兒的孩子，整包一起跟著走            
            3.  找到位置後，孤兒的顏色不用變動
    
                   60(B)
                 /     \
             40(R)      80(R)
            /    \      /    \
         20(B)  50(B) 70(B) 100(B)
                /
             45(R)        
    
        ```
