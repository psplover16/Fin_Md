# 小數的型態與計算

### 1. 型態比較
* **FLOAT**：浮點數、較快、不準確
* **DECIMAL**：定點數、精準
* 💡 **備註**：與錢、成績有關，用 `DECIMAL`。

### 2. 計算函式

```sql
ROUND(x, n) -- 把 x 四捨五入到 n 位小數。
ROUND(14.567, 2) -- ➔ 結果為 14.57
ROUND(14.567, 0) -- ➔ 結果為 15 (捨入到整數)

CEILING(x); -- 把 x 無條件進位到整數
CEILING(14.1) -- ➔ 結果為 15

FLOOR(x); -- 把 x 無條件捨去到整數
FLOOR(14.9) -- ➔ 結果為 14

TRUNCATE(x, n); -- 把 x 無條件捨去到 n 位。
TRUNCATE(14.567, 2) -- ➔ 結果為 14.56 (直接把第三位小數切掉)
```

# 彙總函式
**常見函式**：`COUNT` 計數、`SUM` 總和、`AVG` 平均、`MAX` 最大、`MIN` 最小。

### 使用規則：
1. **放在 SELECT**：當作「計算」欄位。
2. **放在 HAVING**：針對「計算後的結果」設定條件，必須搭配 `HAVING`。
   * 例如：`HAVING SUM(消費金額) > 10000;`
3. **放在 ORDER BY**：拿結果來排序。
   * 例如：`ORDER BY COUNT(員工ID) DESC;`
4. ⚠️ **禁止放在 WHERE**：因為資料庫是先做 `WHERE` 篩選，再做聚合。

### 範例：

```sql
SELECT 
    部門名稱,
    COUNT(員工ID) AS 總人數,      -- 計算：這個部門有幾個人？
    SUM(薪資) AS 總薪資支出,      -- 計算：老闆每個月要發多少錢給這個部門？
    AVG(薪資) AS 平均薪資,        -- 計算：這個部門的平均水準在哪？
    MAX(薪資) AS 最高薪,          -- 計算：這個部門裡的最高薪（通常是主管）是多少？
    MIN(薪資) AS 最低薪           -- 計算：這個部門裡的最低薪（通常是菜鳥）是多少？
FROM 員工表
GROUP BY 部門名稱
HAVING COUNT(員工ID) >= 5       -- 篩選：我只想看「規模大於等於 5 人」的部門 (行政部會被踢掉)
ORDER BY 平均薪資 DESC;          -- 排序：最後的結果，請依照「平均薪資」由高到低 (DESC) 排列
```

# 常用運算子

```sql
SELECT DISTINCT city 
FROM 員工表
WHERE salary BETWEEN 30000 AND 50000 -- 薪水剛好落在 30,000 到 50,000 元之間（包含 3 萬和 5 萬整）的人
  AND dept_id IN (1, 2, 3)           -- 再篩選出屬於「1號、2號，或者 3號部門」的員工。
  AND name LIKE '_大%'               -- 名字第1個字隨便(_) + 第2個字是大 + 後面隨便幾個字(%)
  AND addr IS NULL;                  -- 檢查這些人的詳細地址是不是「沒有填寫」
```
